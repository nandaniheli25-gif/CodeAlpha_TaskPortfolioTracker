CodeAlpha_TaskPortfolioTracker
 
Project overview

The Stock Portfolio Tracker is a Python-based application that helps users track their stock investments. Users can enter stock names and quantities, and the program calculates the investment value using predefined stock prices. It also generates a portfolio summary showing each stock's quantity, price, and total investment. This project demonstrates the use of Python concepts such as dictionaries, loops, conditional statements, and user input handling.


Features

. Add stocks

. Enter quantity

. Check stocks

. Calculate value

. Save details

. Show summary

. Track investment

. Total value

. Easy to use
